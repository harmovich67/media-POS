# PharmaMarket POS Pro — نظام الكاشير الذكي للصيدليات والسوبرماركت

نظام نقطة بيع متكامل (Point of Sale) قابل للتسليم كـ **صيدلية مستقلة**، **سوبرماركت
مستقل**، أو **نظام مدمج شامل** — متوفر بنسختين متطابقتين في الوظائف:

| النسخة | التقنية | الاستخدام المقترح |
|---|---|---|
| 🌐 **نسخة الويب** (هذا المجلد) | React + Vite + Tailwind | متصفح / تطبيق ويب / نشر على استضافة (Vercel) |
| 🖥️ **نسخة سطح المكتب** (`desktop_app/`) | Python + PyQt6 | جهاز كاشير أوفلاين بدون إنترنت |

---

## 1) نسخة الويب

### التشغيل السريع (تطوير)
```bash
npm install
npm run dev
```

### البناء للإنتاج + التشغيل عبر بايثون (خادم مستقل بدون Node)
```bash
npm run build
python index.py
```
سيفتح تلقائياً على `http://localhost:3000`.

### النشر
المشروع جاهز للنشر المباشر على Vercel (`vercel.json` مضمّن) أو أي استضافة ملفات ثابتة
عبر رفع محتوى مجلد `dist/` بعد التنفيذ `npm run build`.

---

## 2) نسخة سطح المكتب (PyQt6)

راجع [`desktop_app/README.md`](desktop_app/README.md) للتفاصيل الكاملة. تشغيل سريع:
```bash
cd desktop_app
pip install -r requirements.txt
python main.py
```

|---|---|---|---|
| الأدمن | `admin` | `123@@##$$456Hh` | كل الشاشات + الإعدادات وتخصيص التسليم |
| ديمو صيدلية | `pharma` | `123` | شاشات الصيدلية فقط |
| ديمو ماركت | `market` | `123` | شاشات السوبرماركت فقط |

## تخصيص نمط التسليم للعميل

من شاشة الإعدادات (⚙ — تظهر لحساب الأدمن فقط) يمكن اختيار:
- **⚡ نظام مدمج شامل** — صيدلية + سوبرماركت مع التحويل بينهما.
- **💊 صيدلية منفصلة فقط** — إخفاء كل واجهات السوبرماركت.
- **🛒 سوبرماركت منفصل فقط** — إخفاء كل واجهات الصيدلية.

وكذلك تخصيص اسم المؤسسة، الشعار، رقم الهاتف، العنوان، الرقم الضريبي، ورسالة أسفل الفاتورة.

## أهم المزايا

- كاشير سريع بالبحث والباركود، مع اختصارات لوحة مفاتيح (F2 بحث، F4 دفع، F8 تعليق).
- إدارة تشغيلات وتواريخ صلاحية الأدوية (نظام FEFO تلقائي) + بدائل الأدوية.
- بيع بالوزن (جرام/كيلو/بالمبلغ) وقسم مائدة وتلاجة بأوزان جاهزة.
- طرق دفع متعددة (كاش، بطاقة، إنستاباي، آجل) مع حاسبة الباقي ونقاط ولاء العملاء.
- إدارة مخزون كاملة مع تنبيهات النواقص وقرب انتهاء الصلاحية.
- إدارة ورديات مع مطابقة درج الكاشير.
- تقارير وتحليلات مبيعات + أكثر المنتجات مبيعاً.
- فاتورة حرارية قابلة للطباعة.
- تصميم متجاوب بالكامل يعمل على كل أحجام الشاشات (موبايل، تابلت، لابتوب، شاشات 4K).
